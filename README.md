# Pediatric Visit Dashboard

An interactive dashboard that turns a CSV of pediatric visits into visit counts, wait times by location, and top visit reasons.

## Quick start

Prerequisite: Node 22.12 or newer (see `.nvmrc`).

```bash
npm install       # install dependencies
npm run dev       # start the development server at the printed local URL
npm test          # run the unit tests once
npm run test:watch # re-run the unit tests as files change
npm run build     # type-check and build the production bundle into dist/
npm run lint      # lint the source with oxlint
```

Full documentation (CSV format, data policies, weather API, assumptions) arrives in a later phase.
